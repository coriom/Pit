## Independently checked illustrative economics

- Portfolio: native Ethereum ETH `1 × $2,000 = $2,000`, Base USDC `500 × $1 = $500`, Arbitrum WETH `0.25 × $2,000 = $500`; known total `$3,000`. Explicit ETH group `$2,500`, or `83⅓%`; largest position `66⅔%`; position HHI `5,000` on the 0–10,000 scale. Adding a positive unpriced holding retains the `$3,000` **known subtotal** but changes coverage to INCOMPLETE and hides whole-portfolio concentration. A separate fictional one-row CSV preview left the portfolio empty until **Accept valid preview**; after acceptance it showed `$2,000`, and the actual local JSON download recorded `knownSubtotalUsdRaw=2000000000000000000000`.
- Swap cost: illustrative CoW-like output `0.005 WETH` already includes venue fees and has no separately paid wallet gas, so estimated net is `0.005 WETH`. Illustrative Uniswap-like output `0.0051 WETH` less `(150,000 + 50,000) × 1 gwei = 0.0002 ETH`, at an explicit `1 WETH/ETH` conversion, yields `0.0049 WETH`. The local JSON reports scenario A ahead by `0.0001 WETH` (`100000000000000` wei). No embedded fee was deducted twice. Clearing B's swap-gas estimate yields `NOT COMPARABLE`, not a zero-gas ranking. These are manual assumptions, not executable quotes.
- Impermanent loss: initial price `100`, final price `400`, initial pool value `1,000` implies a price ratio of `4`, modeled hold value `2,500`, pool value `2,000`, pool-minus-hold `-500`, and impermanent loss `-20%`. The page states that fees, rewards, depeg, deposits and withdrawals are omitted.

## First-use review

The homepage names the task and links directly to the three flagship tools without a wallet. Each tool says what to enter, provides an illustrative example, places the result after the input controls, and states what the calculation cannot determine. Portfolio import requires a visible preview and a separate acceptance click. Results are invalidated when scenario or portfolio inputs change. **Validated reproducible interface defects: none in this pass.** Whether visitors understand the terms and can find the results without guidance is NOT VERIFIED until human testing. Observe, rather than assume, these possible friction points: finding the second Analyze/Calculate click after loading an example; interpreting “known subtotal” when a holding is unpriced; distinguishing estimated net output from minimum receive and actual execution.
