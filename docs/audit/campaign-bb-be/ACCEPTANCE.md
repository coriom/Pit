# PIT BB–BE local-toolbox acceptance

This campaign extends the 95-task private local toolbox with 24 distinct, directly addressable tasks: eight derivative tasks (BB), eight portfolio/statistics tasks (BC), and eight offline DeFi/EVM tasks (BD). The canonical task IDs, routes, categories, input/output descriptions, and completion states are in `docs/product/PIT-TOOLBOX-V1-TASKS.json`; the resumable campaign inventory is `docs/product/PIT-TOOLBOX-BB-BE-PROGRESS.json`. The final catalogue has 119 task experiences, including 113 task pages and six standalone workspace experiences. The 20 existing workspaces remain available. Three new engine modules implement the 24 new tasks; these are not 24 independent calculation packages.

## Models and reference boundaries

- BB uses bounded, scaled-BigInt decimal arithmetic for perpetual PnL, funding, margin, basis, option payoff, and expectancy. Black–Scholes and implied volatility require transcendental functions, so they use bounded IEEE-754 arithmetic, a deterministic 2,048-panel Simpson normal-CDF quadrature, and 80-step bisection. The independent at-the-money call benchmark (spot/strike 100, 5% rate, 20% volatility, one year) is 10.45058357; the unit test checks the calculated price within 0.00000002. These are European no-dividend illustrations, not executable quotes or protocol liquidation rules.
- BC requires synchronized, manually supplied observations. DCA and lot allocation retain exact decimal units where possible. XIRR explicitly rejects multiple-root ambiguity; VaR and expected shortfall describe empirical samples, not predictions. Statistical ratios use bounded numerical arithmetic and disclose their periodicity and sample assumptions.
- BD uses offline, bounded manual inputs. EIP-1559, calldata gas, vault-share and fee-revenue arithmetic distinguish their coverage from actual transaction costs. ABI event and EIP-712 inspections use reviewed pure `viem` utilities without wallet or RPC imports. Nested/unsupported event inputs, noncanonical static words, unsafe object keys and excessive input sizes are rejected. The tick/sqrtPrice conversion is an illustrative deterministic model, not byte-for-byte Uniswap TickMath execution.
- All 24 new pages export local JSON with `browser-local` capability metadata. They are deliberately outside the existing closed workflow-executable pure-tool allowlist. A catalogue entry or downloaded report does not confer execution capability.

## Acceptance evidence and limits

The BB, BC and BD checkpoints were committed and pushed separately. A release-guard false positive against a public 32-byte ERC20 reference vector was corrected without weakening the secret scan; a separate test-only diagnostic was made robust against a transient 100 ms VM startup timeout. Both corrections are committed. Intermediate failures are not acceptance evidence.

The consolidated release gate on clean commit `bf0d4ec` passed: 476/476 Vitest, 92/92 Chromium Playwright, Astro typecheck with zero errors, and full static/security guards. A later test-only mobile performance check and the final normal-CDF accuracy adjustment require a fresh release run on the final clean commit. Firefox isolated-toolbox coverage passed 9 tests with one Chromium-CDP-only performance test skipped; it visited all 137 HTML pages and checked five forbidden routes. This does not establish Firefox acceptance of the full, non-isolated application. The Firefox run was performed using the project's pinned Playwright Firefox binary installed in temporary test infrastructure, with no project dependency change.

The Chromium mobile performance smoke used a 390×844 viewport, 4× CPU throttle and the supported tick boundary of 200000; the measured form calculation was 336 ms, below the 3000 ms test budget. This is one constrained-browser measurement, not a general low-end-device guarantee. The private toolbox host package has 137 HTML pages, 139 served files, 141 total package files, one CSS asset, no JavaScript chunks, exact inline CSP script hashes, noindex and `connect-src 'none'`. The final hash and size must be read from the final committed `pnpm toolbox:check`. The historical six-tool host hash must remain `f2907ac694594531e16ab5501e3be7d066edf98f528553f2bf2164dde725a425`.

Local static/browser evidence does not verify the protected hosted deployment. No new deployment, Vercel change, wallet action, RPC request, transaction, Taxlot write, analytics installation or public publication is authorized or performed here. Public release remains NO-GO; a protected QA deployment requires separate operator authorization.
