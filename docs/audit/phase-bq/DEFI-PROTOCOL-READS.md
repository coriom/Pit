# BQ · bounded DeFi protocol reads

Five distinct read-only Explorer tasks were implemented on Ethereum mainnet. They use the existing fixed dRPC endpoint only after a user submits a form. No address discovery, wallet access, transaction construction, signing, broadcasting, paid provider, backend or deployment was added. The offline Toolbox stays separate with `connect-src 'none'`.

| Route suffix | Actual question | Read boundary |
| --- | --- | --- |
| `uniswap-v3-pool` | What is the pool's sampled spot state? | Reads token0, token1, fee, liquidity and slot0; requires exact registration at the official Ethereum v3 factory and reads both token decimals. Price is token1 per token0, `(sqrtPriceX96² × 10^decimals0) / (2^192 × 10^decimals1)`. Displays 18 decimals truncated plus the exact ratio. No executable quote. |
| `uniswap-v3-position` | What does one position NFT record? | Reads owner and positions on the official Ethereum manager. `tokensOwed` is recorded state, not full accrued fees or withdrawal value. |
| `aave-reserve-index` | What are a listed reserve's normalized indexes? | Confirms asset membership in `getReservesList` and reads income and variable-debt indexes from Aave v3 Ethereum Pool. Raw ray units, not rates or balances. |
| `erc4626-vault-state` | What does a supplied vault self-report? | Reads ERC-4626 asset, decimals, totalAssets, totalSupply and convertToAssets for bounded raw shares. No redeem guarantee or vault-quality assertion. |
| `chainlink-feed` | How old is a feed observation? | Resolves one of two reviewed Chainlink `.data.eth` names through ENS, then reads latestRoundData and compares `updatedAt` with the sampled block timestamp. No local clock or price verification. |

The Uniswap Ethereum factory and position manager are sourced from [Uniswap's deployment list](https://github.com/Uniswap/v3-periphery/blob/main/deploys.md). Aave's Pool address is sourced from the [Aave DAO address book](https://github.com/aave-dao/aave-address-book/blob/main/src/AaveV3Ethereum.sol); [Aave's Pool documentation](https://aave.com/docs/aave-v3/smart-contracts/pool?language=en) defines the ray index semantics. The vault example is listed in [Yearn's own risk report](https://github.com/yearn/risk-score/blob/master/reports/report/yearn-yvdai.md). [Chainlink's ENS guidance](https://docs.chain.link/docs/ens) and [data-feed API reference](https://docs.chain.link/data-feeds/api-reference) define the feed lookup and round fields. These examples are not endorsements or permanent availability guarantees.

All user inputs are bounded and validated before RPC. Every result names the network, provider and sampled block. Public endpoint errors remain visible; no provider fallback occurs. A call budget, timeout and response-size cap remain enforced by the common Explorer RPC boundary. No user-supplied endpoint is accepted. The factory check limits the pool inspector to registered v3 pools, but does not make the spot state a tradable quote. Vault methods and feed answers are self-reported contract outputs.

The Ethereum-only DAO proposal and staking reward inspections were not shipped: this batch did not establish a verified protocol address, ABI and useful live sample. An oracle-versus-AMM comparison was also held back because it would need a reviewed cross-source denomination and freshness policy. These are unsupported, not counted as completed tools.
