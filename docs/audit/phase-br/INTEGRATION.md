# BR · catalogue and architecture integration

The product now has two deliberately separate static candidates. The offline PIT Toolbox keeps 151 individually addressable browser-local tasks, its existing 20 workspaces and `connect-src 'none'`. The new PIT Explorer has 27 individually addressable read-only public-chain inspections under `/inspect/*/`. The two packages have separate Astro entry trees, build commands, route allowlists and CSPs. Neither imports wallet, signing, execution, Taxlot storage or telemetry code. No hosting action occurred.

`docs/product/PIT-TOOLBOX-V1-TASKS.json` remains the authoritative offline task inventory. `src/lib/explorer-registry.ts` is the authoritative Explorer route and metadata registry; it composes BN, BO, BP and BQ tools without dynamic execution discovery. `docs/product/PIT-BJ-BS-PROGRESS.json` records implemented IDs, evidence, substitutions and blockers. `docs/product/PIT-BJ-BS-SURFACES.json` records the aggregate count and deployment boundaries without duplicating calculation definitions.

The Explorer catalogue now has searchable titles and purposes, four task categories, explicit chain labels, a live result count and keyboard-accessible controls. It retains direct links for every inspection. No RPC request is sent while navigating or filtering; only an explicit form submission triggers a bounded read. A focused Chromium test covers search, filtering, keyboard use, all 27 direct routes and zero background network activity.

Completed: 32 new offline tools and 27 new on-chain inspections = 59 new task experiences, 178 total including the prior 119. The campaign target was up to 64; five on-chain slots remain unfilled: BO's definitive revert-reason and ERC-4337 UserOperation inspectors, plus BQ's DAO proposal, staking-reward and oracle-versus-AMM inspectors. BO's full historical Transfer explorer was replaced by a bounded per-receipt event inspector because public `eth_getLogs` was unavailable. BP's global mint/burn event search was likewise not shipped; the distinct ERC-165 interface checker was substituted. BO's blob-fee concept was narrowed to observable blob activity. All substitutions are labeled in the UI. Counts include only implemented routes.

The Explorer is a private, undeployed candidate. Provider rate limits, CORS and method availability were tested for the implemented examples; provider terms and long-term availability require a separate publication review. The offline Toolbox package and historical six-tool beta remain isolated. Complete release, cross-browser and artifact acceptance is reserved for BS.
