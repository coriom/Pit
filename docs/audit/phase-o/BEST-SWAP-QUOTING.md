# Phase O — secretless multi-venue swap quoting

## Boundary audited before the change

`src/lib/cow.ts` previously provided one `quoteSwap` path. `inspectCow` checks the exact Ethereum Sepolia chain, CoW API/settlement/relayer identity, ERC20 code/decimals, wallet balance, approval gas and accounting storage. `quoteSwap` asks the CoW SDK for an exact-input SELL quote. Its returned object contains only display and input data; the SDK, wallet and posting closure remain in a private `WeakMap`. `approveSwap` and `submitSwap` retrieve that closure only after `inspectSwap` repeats the preflight and 60-second expiry checks. `src/components/Swap.tsx` displays the SDK `costsDisplay` values before signature. This execution path and fee configuration are unchanged.

`QuoteProvider.quote(intent)` is a **data-only** interface in `src/lib/swap-quotes.ts`; it has no wallet, signer, calldata, approval or submission method. Provider IDs are closed to `cow` and `uniswap-v3`. The CoW adapter receives an injected quote-only callback to the existing `quoteSwap`; the UI retains that original `SwapQuote` separately for CoW execution and never substitutes a normalized quote. The Uniswap adapter in `src/lib/uniswap-quote.ts` constructs only a public viem client from PIT's already-approved Sepolia RPC and exposes read operations (`eth_chainId`, `eth_getCode`, ERC20 decimals and QuoterV2 `eth_call`). It does not import a wallet client, router, write contract function or transaction request. It returns no calldata. A unit test passes a normalized Uniswap quote to both `approveSwap` and `submitSwap` and observes `QUOTE_EXPIRED`, because it has no private CoW execution closure; injected sign/send spies remain uncalled. The browser fixture observes zero signing calls and no actionable CoW execution button when only Uniswap survives.

## Normalization and ranking contract

The intent is Ethereum Sepolia (`11155111`), exact-input, two distinct ERC20 addresses and a decimal input string. Each provider independently resolves token decimals and produces an integer `sellAmount`; the comparator rejects a mismatch. Parsing rejects fractional precision beyond the token decimals before viem can round it. `NormalizedQuote` records provider, availability, chain, token addresses, direction, sell/buy decimals, integer sell and buy amounts, protocol fee amount/token/rate where known, solver network cost in sell units where known, estimated gas units where available, exact PIT fee in buy units, local quote timestamp/expiry, minimum receive where available, and whether PIT can execute that specific quote. Provider errors become typed unavailable outcomes (`TIMEOUT`, `NO_LIQUIDITY`, `PROVIDER_ERROR`, `MALFORMED_QUOTE`), without discarding other providers' valid results.

`buyAmount` is the exact **quoted output after known provider/protocol fees, before slippage and wallet gas**. CoW uses the SDK's `afterPartnerFees.buyAmount`; its separately disclosed network cost and exact protocol/partner fee values come from the same SDK helper already shown before signature. Its signed minimum remains `afterSlippage.buyAmount`, shown in the original CoW disclosure. Uniswap uses QuoterV2 `amountOut` for the best successful single-pool fee tier; the selected fee tier is included in that quoted output. Because QuoterV2 does not return an exact token-denominated fee amount, this is shown as a fee **rate**, not a fabricated amount. Its gas estimate is **gas units**, not a buy-token cost. CoW wallet gas for a possible ERC20 approval is separate. Both normalized PIT fee amounts must be exactly `0n`; `FEES_ENABLED=true` rejects the quote intent in this release.

Ranking uses only BigInt `buyAmount`, never floating-point token quantities. At least two quotes must be available and fresh, with identical chain, direction, addresses, token decimals and integer sell amount; their quote timestamps must differ by at most 10 seconds. CoW expires at 60 seconds, Uniswap at 30 seconds, and both are reclassified as stale by a UI clock. If only one survives, the UI says there is no best-output comparison. If two outputs tie, both providers are named. The label is **“Best quoted output (gas excluded)”**; it is not a universal net-best or execution recommendation. No gas-to-buy-token conversion is attempted.

A deterministic same-input test uses one sell token with 18 decimals and one buy token with 6 decimals: sell `1,000,000,000,000,000,000` base units; CoW quotes `2,000,000` buy base units and Uniswap quotes `2,000,001`. The BigInt comparator selects Uniswap by **one** buy base unit. The UI explicitly says that Uniswap is quote-only and cannot be executed through PIT. A separate fixture uses outputs above `2^53` to prove exact integer ordering; ties, stale data, decimal mismatch, asset/chain mismatch and freshness skew are negative-tested.

## Failure isolation and browser request inventory

`collectQuotes` runs providers concurrently and applies an eight-second timeout to each outcome. A timed-out transport request may continue in the background, but its late result cannot update the completed comparison or trigger execution. A CoW wallet-provider read failure leaves a valid Uniswap read-only quote visible; Uniswap pool reverts/no liquidity, a transport error, malformed response or timeout cannot erase a valid CoW quote. The [keyless Playwright request capture](runtime-inventory.json) contains only the pre-existing origins `api.cow.fi`, `api.hyperliquid-testnet.xyz` and `ethereum-sepolia-rpc.publicnode.com`; QuoterV2 adds RPC methods `eth_call`, `eth_chainId` and `eth_getCode` on an already-approved origin. It records no credential headers and zero signing calls. The test intercepts external HTTP with fixtures and rejects secret-like request body/query/header fields, so it is evidence about the exercised synthetic flow, not every possible injected wallet extension.

The Phase L artifact/CSP/SRI and Phase N discoverability/bundle guards remain in `pnpm release:check`; no CSP host, API key, dependency or executable venue was added. The final exact release output is in [release-check.txt](release-check.txt). Assumption 8 remains OPEN because there is still no independently verified dedicated public HTTPS origin. Live Phase H acceptance remains blocked pending funded external testnet wallets and operator-approved signatures.
