# BS · PIT toolbox expansion acceptance

## Scope and decision

Baseline `main` was `a681796699ea504168ebe389f4dea56a98068f14`. BJ–BM delivered 32 genuinely new offline task experiences; BN–BQ delivered 27 read-only public-chain inspections; BR integrated the separate catalogue. The product now has **178 distinct direct task experiences**: 151 offline Toolbox tasks and 27 Explorer inspections. This is 59 new capabilities, five short of the optional 64-target; no aliases or unsupported placeholder pages were counted. `docs/product/PIT-BJ-BS-PROGRESS.json` lists every implemented ID, substitution and blocker. `docs/product/PIT-BJ-BS-SURFACES.json` records the separate capability and package boundaries.

Local integration: **PASS for protected QA review**. Public release: **NO-GO**. Neither package was deployed in this campaign. The Explorer has public-RPC availability and publication-term risk and is not a guaranteed live service. Existing protected Vercel and unpublished Cloudflare configurations were not changed. Full hosted HTTPS behavior is not asserted from local package tests.

The offline package preserves `connect-src 'none'`, noindex, explicit route/file allowlists and no wallet, RPC, execution, Taxlot storage or telemetry bundle. The Explorer is a different static entry tree: its CSP permits only `https://eth.drpc.org` and `https://base.drpc.org` for explicitly initiated reads. Its RPC wrapper checks chain IDs and sampled blocks, limits methods and calls, imposes a 10-second timeout and 64-KiB response cap, and never accepts a custom endpoint. The package guard rejects executable RPC methods, wallet APIs, browser accounting storage, analytics and unexpected assets. The public provider sees submitted addresses, token contracts, hashes or names. No private keys or browser wallet data are requested. Built artifact checks do not prove the behavior of a future host until separately deployed and tested.

The [dRPC public-node rate-limit documentation](https://drpc.org/docs/howitworks/ratelimiting) describes public nodes as free but rate-limited; a 429 occurred in Firefox acceptance. [dRPC's plan table](https://drpc.org/docs/pricing/plans) distinguishes public nodes from paid tracing/archive capabilities. No subscription or paid endpoint is part of this candidate. Long-term availability and permitted commercial publication of this particular Explorer still require operator review before any public deployment.

## Unsupported and narrowed proposals

BO did not ship a definitive revert-reason inspector or ERC-4337 UserOperation lookup because the reviewed public methods were unavailable or not supported. Historical ERC-20 transfer search was narrowed to one receipt's Transfer-signature events; blob fee quotation was narrowed to blob activity. BP substituted a bounded ERC-165 interface claim checker for global mint/burn history because the free log-query path was unavailable. BQ did not ship DAO proposal, staking-reward or oracle-versus-AMM comparison pages without sufficient verified contract and denomination evidence. This leaves five unfilled on-chain slots and several clearly labeled substitutions. No protocol-specific read is described as a safety audit, guaranteed trade quote, complete portfolio or forecast.

Public access, indexing, monetization and legal/accounting launch decisions remain outside this campaign. `FEES_ENABLED=false`, `MAINNET_ENABLED=false` and `UNISWAP_EXECUTION_ACCEPTED=false` remain unchanged for execution. Historical Assumption 8 remains open for trading/accounting scope and is not resolved by local-tool tests.
