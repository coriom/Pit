## Adapter and comparison boundary

[`uniswap-execution.ts`](../../../src/lib/uniswap-execution.ts) pins chain 11155111, router, factory, quoter, the exact WETH/USDC pair and fee 500. Before an execution quote it checks wallet address and chain, approved IndexedDB origin, deployed code, router factory/WETH identity, factory pool address, pool factory/token/fee/liquidity/initialization, and exact sell balance. The quote is retained in a private WeakMap bound to the original wallet and object identity; copies, normalized display quotes, changed economics and expired quotes cannot reach approval or swap. It computes minimum output with integer arithmetic at 0.50% slippage. The router calldata is encoded and independently decoded against SwapRouter02's exact-input tuple. Approval targets only the router and exact sell amount. The separate `OperatorCheckpoint` requires an explicit review before each wallet action. A successful approval invalidates the quote so a fresh one is required before swapping. Each transaction is one-shot; no automatic retry exists.

[`uniswap-fill.ts`](../../../src/lib/uniswap-fill.ts) would record a spot `trade` only after a successful Sepolia receipt and exact ERC-20 Transfer-log reconciliation. It keeps the pool fee inside received output, wallet-paid gas separately in raw evidence, and PIT fee zero. The unchanged `appendEvent` transaction deduplicates by transaction hash; a reverted receipt or transfer mismatch cannot create a successful event. Its local tests validate schema-compatible CSV output and duplicate/revert behavior. **This path has not yet been exercised with a real Uniswap settlement or the Taxlot Generic importer.**

The existing comparison still uses exact chain, token identities, direction, decimals and total sell budget. For this phase the Uniswap comparison is limited to fee 500. CoW's solver network cost is embedded in the sell budget; Uniswap's pool fee is embedded in quoted output, while approval and swap gas are separately wallet-paid and not priced into the cross-venue ranking. The only ranking claim is *best quoted output excluding separately paid gas* when the normalized quotes satisfy the existing freshness and identity rules. No cheapest-overall claim is made, and venue selection never silently substitutes CoW for Uniswap.
