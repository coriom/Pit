## Security and remaining gate

The test-only worktree helper and signer bridge live under `scripts/audit/`; production modules do not import them. The release invariant rejects a transformed production gate and the artifact guard rejects test-signer markers or secret-loader content. Regression tests cover the one-line transformation, extra source changes, wrong served hash, occupied localhost port, stale quote, safe failure classification, and wrong router, wallet, token, amount, calldata, or value in the simulated gas path. Existing execution/signer tests retain wrong-chain, mainnet, exact-approval and one-shot transaction restrictions. The normal source/build remains disabled; the isolated preflight does **not** authorize or establish live Uniswap acceptance.

Before a separately authorized live attempt: freshly verify the account and pool state, obtain a fresh quote, re-estimate live approval and swap gas, review the short quote lifetime, preserve exact approval and minimum-out guards, and obtain new explicit operator authorization. Receipt, actual token deltas, Taxlot persistence, CSV/import reconciliation and no-duplicate accounting remain untested for Uniswap. Assumption 8 and legal/mainnet gates remain open.
