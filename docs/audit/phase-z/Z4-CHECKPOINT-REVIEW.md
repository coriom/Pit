## Narrow correction

The approval checkpoint now has a separate preflight and exact approval scope: Sepolia `11155111`, Circle test-USDC `0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238`, SwapRouter02 `0x3bFA4769FB09eefC5a80d6E87c3B9C650f7Ae48E`, WETH `0xfff9976782d46cc05630d1f6ebab18b2324d6b14`, and exactly `10000000` sell base units. It still requires an original privately retained quote, unchanged fingerprint and wallet, current factory/pool identity, token balance, current allowance, gas estimate and ETH headroom. It does not require the **swap** quote to remain live merely to approve exact allowance. The handler independently encodes/decodes approval calldata, marks the attempt before the wallet call to prevent automatic retry, verifies the synthetic/real receipt and allowance, then invalidates the quote. An approved allowance never authorizes a swap: the user must request a new wallet-bound quote, pass fresh swap preflight and separately confirm the swap. Swap expiry, minimum output and slippage checks were not relaxed. The execution flag remains false in ordinary source.

The runner now records bounded, safe UI checkpoint snapshots: gate state, element presence/visibility/enabled state, sanitized alert, quote lifetime and whether a mock wallet request occurred. It rejects a foreign port-4397 listener and byte-compares the served raw module with the exact transformed disk source. Vite's raw-module template-literal form is accepted only when the body is byte-for-byte identical and trailing content is absent or an inline source-map comment; executable trailing content is rejected. The isolated mock uses real Sepolia reads initially, then memoizes unchanged read-only answers within its disposable session to prevent repeated polling from consuming the entire 30-second quote. The memoization and synthetic receipt exist only in the audit runner, never in browser production source. This is a simulated lifecycle, not a market-freshness or live-settlement result.
