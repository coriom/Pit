# PIT V2 catalogue foundation

PIT Free keeps all 151 offline Toolbox experiences and 27 separate read-only Explorer inspections free. The 20 existing Toolbox workspaces remain available as broader interfaces; they are not counted again as distinct experiences. No account, wallet, subscription, or prepaid credits are required to use the free products.

Nine user categories organize the catalogue: Trading & Risk; Blockchain Explorer; Token Creator; Token Management; Transfers & Airdrops; Vesting & Locking; DeFi & Liquidity; Portfolio & Analytics; and Developer Tools. The V2 adapters derive available routes, names, limitations, networks, and status from the existing reviewed task and Explorer registries. They do not authorize execution or create a second list of live tools. The offline and Explorer packages remain separate.

PIT Operations is a future, separately reviewed product direction. The seven proposed operations in `v2-catalog-core.ts` have no routes, forms, contracts, checkout, wallet actions, or payment verification. Their USDC amounts are indicative PIT service-fee proposals only. A future operation must disclose its network, payment asset, PIT service fee, independently estimated blockchain gas, total estimated cost, and status before asking for wallet consent. No total quote can be produced from the current metadata.

PIT Analytics currently comprises the free calculators and inspections. A paid, one-time advanced report is only a proposal in this catalogue; the existing disabled billing and report infrastructure is retained outside both free static packages. No imported financial dataset is routinely stored by these catalogues.

The current private/noindex build and release approval gates remain in force. Existing execution flags and Phase CE SIWE work are outside this frontend change. Hosted SIWE acceptance remains unverified.
