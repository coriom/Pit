These drafts are for the six browser-local calculators only. They require publisher, hosting and jurisdiction review before any public pilot. No notice route is included in the eight-page candidate until the missing facts are supplied and reviewed.

## Privacy notice draft

PIT's read-only beta calculators work on information you enter in your browser. Portfolio CSV preview, calculations and JSON downloads occur locally. The candidate does not connect a wallet, request balances or prices, send calculation fields to PIT, or install application analytics. It does not write to PIT's trading/accounting IndexedDB stores. Do not enter sensitive personal data when trying illustrative examples.

Loading a hosted page necessarily sends ordinary HTTP request metadata, such as IP address, browser information, path and time, to the hosting provider. The hosting provider may process or retain that metadata under its own configuration and policies; PIT cannot claim that the host sees nothing. A protected QA deployment may also use Vercel Authentication and its session cookies. The operator must verify actual host configuration, retention, jurisdiction and any access logs before publishing this notice.

Feedback, if later invited, is optional and handled outside the calculator. Ask participants for observations about usability, not wallet addresses, positions, CSV files or monetary input values. Specify the actual contact channel and retention period before collecting feedback.
